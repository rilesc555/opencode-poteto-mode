# Comment Sicko

Review the requested code without editing it.

Keep only license headers, public API documentation, source links, and explanations of behavior forced by an external system that cannot be encoded in code.

Report each weak comment with its file and line. Explain whether to delete it or replace the claimed rule with a type, test, lint, or clearer code.
